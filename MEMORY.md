### Устройство панели (состояние на вечер 16.09.2026)
- Левый рельс категорий: BODY / FACE / SKIN / HAIR / CLOTH / PRESET.
- Полоса чипов — секции активной вкладки. **20 страниц**: BODY 1, FACE 6

- Активна **ровно одна** страница из **всех** вкладок. Всего 164 слайдера.
- Нижняя панель: RANDOM / RESET / BACK / NEXT.
- Строка параметра: подпись 148 (фикс.), значение 46, дорожка тянется — замер **341 из 555

- Цвета: сетка из 12 свачей + H/S/V для тонкой подстройки.
- Оформление: тёмная база + золотой акцент; скруглённые 9-slice, градиент и круглый бегунок

- Камера: принадлежит панели (`LateUpdate`), направление орбиты зафиксировано на **+Z**

- Свет: в сцене активен только контровой `Point Right_Front`; панель добавляет рантайм-источник
  `MAC_FrontFill` между камерой и аватаром и ведёт его за кадром.

### Грабли (проверено на практике, не теория)
- **Прозрачные страницы + все вкладки активны.** Если гасить страницы только текущей вкладки,
  контент просвечивает друг через друга и перехватывает ввод («ползунки не пропадают»,
  «кнопки без функционала»). Гасить страницы **всех** вкладок.
- **Нативный `UIManager` продолжает работать** после скрытия своего UI и на **каждый клик ЛКМ**
  переставляет `Camera.main` в `focusPos.z + _currentCameraDistance` (мировая ось +Z), из-за чего
  камера «проваливается сквозь тело». Камеру забирать себе из `LateUpdate` (после `Update`) и
  хранить **своё** направление орбиты, а не читать позицию камеры обратно.
- **Направление орбиты нельзя выводить из текущей позы камеры** — она может быть позади
  аватара, и тогда виден зад. Фиксировать на +Z.
- **Ограничение дистанции — в момент ПРИМЕНЕНИЯ**, а не только там, где пишет колесо.
- **Дочерний фон внутри строки с `HorizontalLayoutGroup` становится layout-ребёнком** и
  сжимается до ширины спрайта (~14 px вместо 555). Лечится `LayoutElement.ignoreLayout = true`.
- **Префабы причёсок/одежды несут `LODGroup`** с reference point на голове, а инстанс паркуется
  у ног → группа отсекает объект. Удалять `LODGroup` у инстанса.
- **У бегунка слайдера можно случайно получить высоту 0** (`sizeDelta = (12,0)`) — тогда ползунок
  выглядит как прогресс-бар. Задавать `anchorMin/Max=(0.5,0.5)` и `sizeDelta=(14,14)`.
- Сцена ~30 МБ YAML — править только через мост к редактору, не руками.
- Пересборка префабов/объектов рвёт привязки UnityEvent — **переносить** объекты, не пересоздавать.
- Редактор не всегда подхватывает правки скриптов (окно не в фокусе) — после правки послать
  `refresh` или `menu item=Assets/Refresh`, иначе компиляции не будет.
- **Рекомпиляция во время Play оставляет «залипшее» состояние** панели (пустые списки при живых
  объектах). Для проверки — чистый перезапуск Play.
- Консоль PowerShell искажает кириллицу, из-за чего легко сделать ложный вывод «файл в cp1251».
  Проверено: `CONTEXT.md` и `MACCustomizationUI.cs` — **UTF-8**. Доверять байтам.
- Python — с `PYTHONIOENCODING=utf-8`. Патчить файлы байт-в-байт (round-trip через latin-1),
  многострочные якоря нормализовать по CRLF. **Перед перекодировкой целого файла — копия.**
- Перед правками — бэкап в `AI\backup-<дата>-<тема>\`.
