## Три вещи, которые сэкономят тебе часы

**1. Поле команды называется `op`, а не `cmd`.**
```json
{"id":"0001","op":"ping","args":[]}
```

**2. Не угадывай время компиляции через `sleep`.** Опрашивай `Library/ScriptAssemblies/*.dll`, пока его время не станет новее самого свежего `.cs`. Иначе получишь старый стектрейс и решишь, что правка не работает. Подробности и готовый скрипт — в `AI-BRIDGE-GUIDE.md`, раздел 6.

**3. Проверяй, в какую сборку попадает твой файл.** Рядом с `.asmdef` код собирается отдельно, не в `Assembly-CSharp.dll`.

## Ни один проект не под git

Перед правками делай копии:
```bash
mkdir -p "<ProjectRoot>/AI/backup-$(date +%Y%m%d)"
cp "<файл>" "<ProjectRoot>/AI/backup-$(date +%Y%m%d)/"
```

Всё, что мост меняет в сцене, идёт через `Undo.*` — отменяется обычным Ctrl+Z. Но правки файлов Ctrl+Z не отменяет.
