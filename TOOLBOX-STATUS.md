## 4. Две грабли, обе воспроизведены и обойдены

1. **Прокси.** CLI неверно разбирает системный прокси (`http://127.0.0.1:10809` → `http://http//...`),
   из-за чего сетевые шаги падают с «Этот хост неизвестен». Решение: **`--proxy-disable`**.
2. **Пакет не подхватывается без перезапуска** — в проекте отключено «Auto Refresh» (этим же
   объяснялось, почему скрипты не компилировались без ручного refresh). Решение: перезапуск редактора.

Плюс: `eval` не принимает код с кавычками из командной строки (шелл разбивает его) — использовать
**`eval_file`** с `.cs`-файлом вне `Assets/`.
